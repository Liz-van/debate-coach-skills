# debate-coach-skills

中文辩论备赛的一套技能包（Agent Skills）：从拿到辩题，到出正反两套立论、跑一场完整的九人赛制比赛，再给外行出一份不站队的「辩题速览」。

核心不是「让 AI 帮你写篇稿」，而是**双持方对抗**：同一道题，让两个 Agent 各站一边互相打，收敛之后再落稿。

面向能读本地技能目录、能起子 Agent 的 Agent 环境（DSH / Claude Code 一类）。

## 四个技能

| 技能 | 触发 | 做什么 |
|---|---|---|
| `argument-construction` | `$立论 <辩题> <持方>` | 单持方深度调查报告 md + 资料表 xlsx。内部本来就起两个 Agent 分饰我方与对手 |
| `dual-side-argument` | `$立论 <辩题>`（不写持方） | 正反两方各出一套完整立论，各跑一遍硬质检，最后给对位比较 |
| `debate-9` | `$立论 <辩题>`（不写持方） | 九人赛制全程：11 个 teammate、四对四打 2/3/4 场、每场 13 个发言单元、评委 7 张技术票 + 1 张印象票，最后交付两套立论 + 各辩位稿件 + 一份《辩论实录》 |
| `motion-brief` | `$评赛 <辩题>` | 中立「辩题速览」md（可转 PDF 发人）：不站队、不查资料、不做攻防预判 |

`dual-side-argument` 与 `debate-9` 的触发条件相同（都只给辩题、不给持方），按意图区分：只想快点拿到正反两套立论走前者，想真打一场完整比赛走后者。两者都会从 `argument-construction` 取版块、写作风格、诊断卡、资料协议和脚本，所以**四个目录要放在同一个技能根目录下一起用**。

## 三个真不一样的地方

1. **对抗是真起两个 Agent，不是自我批评。** 单持方模式下是「我方 Agent + 一个专门来打的对手 Agent」；双持方模式下两个 Agent 天然就是对方的对手（正方 Agent 同时扮反方去打反方草案），因此没有一个是假设出来的对手。两方必须用同一模型、同一思考等级——否则模型差异会被误当成论证差距，两条对抗线的裁决一起失效。

2. **硬质检卡点，过不了不许出文件。** `check_debate.py` 的几条硬项：首轮草案登记的论点少于 3 条直接失败；对抗裁决后「存活 + 修补后存活」的论点必须 ≥3；只扫报告第 4 节的持方论点体系，一旦出现「对方会…／对方可能…／反方会…」就报错——逼你把对手的话留在对手那一栏，不许在自己的论点体系里替对手说话。一方硬项失败时不许只交另一方的半份成品。

3. **去 AI 腔 14 条。** 写进 `argument-construction` 的写作风格小节：禁宣传腔、禁模糊归因、禁句尾「凸显／体现」、禁排比堆砌；要求用大白话、不拟人不比喻、术语第一次出现给一句解释。清单同样适用于《辩论实录》。

## 安装

把 `skills/` 下的四个目录复制进你的技能根目录：

```
~/.dsh/skills/        # DSH
~/.claude/skills/     # Claude Code
```

技能文档里的路径统一按 `~/.dsh/...` 写。换到别的 harness 时替换三处即可：

| 文档里的写法 | 换成 |
|---|---|
| `~/.dsh/skills` | 你的技能根目录 |
| `~/.dsh/tmp` | 任意临时目录（中间 JSON、HTML、PDF 都落这里，交付目录不留临时文件） |
| `~/debate` | 你的备赛工作目录（`~/debate/备赛`、`~/debate/评赛` 会自动建） |

## 运行依赖

- **Python 3.10+** —— `check_debate.py` / `precheck.py` / `generate_report.py` / `check_match.py` / `count_speech.py` / `speech_bands.py`
- **openpyxl** —— 生成资料表 xlsx
- **PDF 环节**（`generate_report.py pdf`、`md2pdf.py`）——可选，不出 PDF 不影响其余部分。本机实现依赖 pandoc + weasyprint，且 CSS 里指定了 Windows 自带中文字体「微软雅黑」，非 Windows 环境需要自行改字体

脚本里有几处针对 Windows 的处理（控制台默认 GBK 时强制 UTF-8 输出，避免 ✓/✗ 报 UnicodeEncodeError；读带 BOM 的 JSON；文件名过滤 Windows 非法字符），在 Linux/macOS 上不影响运行。

## 关于这份代码

- **实战打磨**：这套技能是在真实备赛里迭代出来的，跑过三场完整的九人赛制比赛，并按赛后复盘改过质检项。
- **已做路径脱敏**：原作者机器上的绝对路径（技能目录、临时目录、备赛目录、Python 解释器路径）已替换为上表的通用路径，技能逻辑本身未改动。
- **诚实说明**：技能正文与脚本大多是与 AI 协作产出，经本人逐轮试用与反复修正，不是纯手写。
- 赛题、稿件、报名信息等备赛资料**不在本仓库内**。
