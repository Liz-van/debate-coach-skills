# Excel 资料表格式规范

`scripts/generate_report.py xlsx` 已内置实现，**AI 只负责填数据**，不需要手工调格式。

## Sheet 结构

顺序固定：封面 / 辩题诊断卡 / 核心对象原型资料 / 反方观点与反驳 / 事实交锋点 / 来源索引 / 概念界定（可选，有才建）/ 论点一、论点二……（每个论点一个 sheet）。

文字性板块（判准、论点论述、攻防预判、质询结辩建议）**只进 md，不进 Excel**——Excel 保持纯粹资料表定位。

## 格式规范（脚本已实现）

1. 所有 sheet 隐藏网格线；A 列留白占宽（宽约 3）；第 1 行留空
2. 第 2 行标题（14pt 加粗），第 3 行小字注释（灰色），第 4 行表头，第 5 行起数据，冻结表头
3. 表头：深灰深蓝底（333333）+ 白色加粗字，不用蓝色或其他彩色表头
4. 数据行：白色与浅灰（F9F9F9）隔行交替，配极浅灰框（DDDDDD）
5. 字体：中文用黑体类（微软雅黑），正文 10pt；编号、数字用衬线体（Cambria）
6. 超链接：蓝色（0563C1）+ 下划线，真正可点击
7. 所有内容列自动换行，按内容长度估算行高；列宽按内容类型分配（编号窄、内容宽）

## 新增列

- **证据状态**：已核验 / 部分核验 / 未核验 / 来源冲突
- **来源类型**：官方统计 / 学术 / 机构报告 / 权威媒体 / 案例

## 数据 JSON 结构

见 `scripts/generate_report.py` 顶部注释：`sheets[]` 每项含 `name / title / note / headers / rows / link_col / widths`；`rows` 可用 `{"divider": "—— 区块名 ——"}` 与 `{"summary": "小结：…"}` 表示灰底分隔行与加粗小结行。
