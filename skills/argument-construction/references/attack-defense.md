# 攻防构造：steelman、反驳四步、质询、靶点

> 方法框架整理自 athena-caixinying/debate-prep（MIT）与 hellobiyue/debate-prep-workbench（MIT）。

## 一、Steelman（强制）

写「反方观点与反驳」前，先用**对方能认可的语言**写出其最强合理版本：

- 用对方的最佳证据，不是最弱的
- 用对方最合理的定义和判准
- 不妖魔化、不省略对方的让步空间

只有对方最强版本被写出来，后面的反驳才算数。

## 二、反驳四步

1. **准确复述**：一句话复述对方主张（对方看了也认）
2. **争议层级**：指出分歧发生在事实 / 机制 / 概念 / 比较 / 影响哪一层
3. **给出理由**：理由、反例或证据
4. **回到比较**：说明这一点如何改变胜负比较（不是「对方错了」就结束）

## 三、质询：问题树 + 四分支 + 退出句

每组问题聚焦**一个目标**（要拿到什么共识、暴露什么矛盾）。

```
问题组 [目标]：
主问题：
  - 对方答「是」 → 追问：
  - 对方答「否」 → 追问：
  - 对方「回避」 → 追问：
  - 对方「反问」 → 回应：
收束句：拿到 X，如何回到判准
退出句：若三次追问无果，用 ____ 收场，不再耗时
```

规则：

- 主问题尽量短，**只含一个命题**
- 「小结」只写场上**实际**拿到的承认、矛盾或未回应，**不虚构战果**
- 不要为了显得强势反复说「只回答是或不是」；需要限制答案时说明问题前提，保持礼貌和控制力

## 四、可控靶点（可选板块）

引对方进入我方准备充分的争议。模板：

```text
T-ID：
表层主张：
对方最可能攻击：
第一层回应：
保留的第二层解释：
如何反压回我方战场：
不可退让口径：
放弃该靶点的条件：
```

**红线**：靶点必须是真实、清晰、可辩且已充分防守的主张。不得留假数据、偷换概念或误导性省略——那不是战术，是把柄。

优先选择能暴露对方**过高证明责任、错误二分、因果跳步或标准不一致**的靶点。

## 五、结辩结构

- 结辩围绕**已经发生的交锋**组织，不是预写全文
- 提炼 2-3 个真正决定胜负的分歧
- 说明双方在每个分歧上各自完成或未完成了什么举证
- 把零散证据重新放回判准和影响比较
- 价值收束应从前文自然推出，不新开未经论证的大论点
- 场上总结必须占实质篇幅，升华在后
