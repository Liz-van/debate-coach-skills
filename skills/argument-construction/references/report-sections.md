# 报告版块详细写法（0-11）

主稿只承载**可上场/可查阅的备赛内容**。工作信息（问题地图、搜索诊断、核验限制、待补资料、自检记录、版本改动清单）只进附录。

## 0. 封面

辩题、持方、制作日期、交付档位、版本说明（首次 v1.0，后续修改递增并附改动记录）。

## 1. 辩题诊断卡与判准

- 诊断卡全文（模板见 `motion-diagnosis.md`）
- 由诊断卡推出的**判准建议**：表达完整、不刻意缩短；说明为什么该判准有利于我方持方
- 判准必须与诊断卡的「论证结构 + 关键词证明标准 + 举证责任」一致，**不得自相矛盾**

## 2. 辩题拆解

表格梳理三层交锋：

| 层级 | 核心问题 | 双方必争 |
|---|---|---|
| 事实层 | | |
| 价值层 | | |
| 身份层 | | |

## 3. 概念界定（可选）

触发条件：辩题需要重新定义核心概念，或讨论对象做了抽象化处理时增设。

- 自圆其说、内部一致；脱离一般认知的程度越小越好
- 服务己方论点，但不显得在「打补丁」
- 给出操作性定义（比赛中可用），写清我方口径与边界
- **不得把结论直接塞进定义**

## 4. 持方论点体系

**论点固定 3 个**（三档一致，不随详细程度变化：精简 / 标准 / 完整都是 3 个，档位只加证据密度与对抗轮数），且必须是**双 Agent 对抗裁决之后**仍存活的版本（存活 / 修补后存活）；少于 3 个先回炉补料或改结构，不许硬凑。每个论点按三段式写（逻辑链预览 / 展开叙述 / 收束），见 `argument-chain.md`。

**只写我方主张**：本节不出现「对方会说……」「反方可能……」这类预判——立论环节不预判反驳，对方视角一律放第 6、8 节。修补痕迹也不写进正文（不写「有人质疑……但其实」），改完就是干净的主张。

**讨论轮只动受影响的那一处**：用户标 `【讨论】` 后追加的对抗轮如果裁到本节，只改被裁到的那个论点或那一段，改动逐项记进 `debate.json` 的 `changed[]`；**不许借讨论轮把本节重写一遍**，也不许顺手改与靶心无关的内容（详见 `adversarial-debate.md` 第九节）。

## 5. 核心对象原型资料

表头：`编号 | 类别 | 内容 | 关键细节 | 来源 | 证据状态`

## 6. 反方观点与反驳

表头：`编号 | 对方最强版本 | 依据 | 反驳四步 | 证据状态`

- 「对方最强版本」用对方能认可的语言写（steelman）；**优先直接用对抗收敛中对手 agent 的真实攻击版本**，而不是重新想象一个稻草人——讨论轮（【讨论】）打出来的真实攻击同样优先用在这里
- 「反驳四步」压缩成一句：复述 → 争议层级 → 理由/反例 → 如何改变胜负比较
- 详见 `attack-defense.md`

## 7. 事实交锋点

表头：`交锋点 | 我方事实 | 对方可能事实 | 应对思路`（应对思路含归因层面对照资料）。无来源列，事实句末标 `[来源X]`。

## 8. 攻防预判

攻防对话格式（**不用表格**）。排版要求必须遵守：

- 每组攻防之间**空一行**分隔，不能首尾相连
- 组内每一句**独立成段**：「对方可能打」标题、对方说、我方回、对方追问、我方再回各自单独一行，行与行之间空一行
- **禁止**把整组攻防连写成一大段连续文本

示例：

```
【对方可能打：XXX】

→ 对方具体怎么说

回：我方怎么回应

→ 对方可能追问

回：继续回应
```

## 9. 质询与结辩建议

- 质询用追问链格式：定义切割 → 反例测试 → 价值收束；每组附「是 / 否 / 回避 / 反问」四分支与退出句
- 结辩给核心价值收束方向 + 2-3 个决定胜负的分歧

## 10. 论点资料区

**每个论点一个表格**（二级标题 + 表格），表格间天然分隔，不需要额外分隔行。两种形式：

- **资料列举型**（适合「摆事实」论点）：`编号 | 维度 | 数据/事实 | 核心内容 | 来源 | 状态`
- **对照型**（适合「错对/优劣比」论点）：`编号 | 对照类别 | 人物/对象 | 起点（选择与行动）| 现状/结果 | 来源 | 状态`

内容分块时用一行 `—— 区块名 ——` 隔开（如「当下环境」/「当年环境」），块间编号连续；末尾可加一行「小结」，对照型末尾可加一行「洞察」（如幸存者偏差声明）。

两种形式都不适合时：**生成前停下来**，建议新形式并说明理由，等用户确认后再做。

## 11. 来源索引

表头：`编号 | 来源名称 | 类型 | 核心内容 | URL | 证据状态`。URL 必须是可点击超链接。

来源编号**全报告统一**（md 与 xlsx 一致）；正文引用写 `[5]` 或 `[5,7,8]`。

## 附录（不进正文）

问题地图、搜索计划与日志、证据核验记录、来源冲突说明、待补资料清单、论证链自检记录（草案版 + 终稿版）、版本改动清单。

**对抗收敛记录**（新）：轮次与角色（谁扮我方、谁扮对手、是否走了 `spawn_teammate` / `subagent` / 单 Agent 分饰兜底）、每轮攻击表（目标论点 / 环节 / 严重程度 / 攻击主张 / 依据 / 最低修补要求）、修补表（处理动作 / 具体怎么改 / 代价）、裁决表（结论 / 理由）、未闭合项与已让步删掉的论点。**讨论轨（【讨论】）的轮次与裁决并进同一份记录**，不另开小节。表格与 `debate.json` 一致，`check_debate.py` 的预检结论一并附上。
