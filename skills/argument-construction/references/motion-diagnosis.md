# 辩题诊断与举证责任

诊断卡是整份报告的根：判准从它推出，论点义务按它分配，反驳按它打。

> 方法框架整理自 athena-caixinying/debate-prep（MIT）与 hellobiyue/debate-prep-workbench（MIT）。

## 一、诊断顺序

先把辩题改写成一个待证明的逻辑命题，再依次判断：

1. 要证明的是**行动应当性、规范评价、经验事实、因果效果、责任归属还是概念解释**？
2. 双方是在证明单方成立，还是**比较 A/B、现状/方案、程度、趋势、必要性或归责**？
3. 辩题中的**主体、对象、场域、时间和隐含参照系**是什么？
4. 关键词要求证明「存在」「通常如此」「净效果为正」「更优」「不可替代」还是「必须」？
5. **哪一方主张改变现状、扩大义务或提出更强的普遍命题**？据此分配举证责任。

不要只按题面的「应不应该」「更」「是」等单字机械分类，要看整句逻辑和赛题语境。

## 二、命题类型

**政策行动型**：是否采用、废除或改变制度与行动。检查现状、目标、方案、执行者、机制、成本、副作用和替代方案。我方（正方）需证明问题重要、方案有效且净收益优于现状或合理替代；反方不必证明现状完美，可证明问题被夸大、方案无效、成本过高或存在更优替代。

**价值评价型**：正确、值得、重要、进步、奖赏、惩罚等规范评价。明确评价对象、承受主体、评价尺度和冲突价值。不能只证明己方「有好处」，要证明己方尺度更合题且在共同尺度下更优。

**事实描述型**：某现象是否存在、普遍、严重或正在变化。明确可观察指标、时间范围、总体与样本；**避免用个例证明普遍命题**。

**因果效果型**：A 是否导致、促进、阻碍 B。拆机制链，检查时间先后、混杂变量、反向因果、选择偏差和净效果。注意「有助于」通常只要求非微不足道的正向贡献，不等于充分解决。

**责任归属型**：有错、应负责、应受谴责或负有义务。区分事实错误、实践理性矛盾、道德或法律义务违反；**不得从「结果较差」直接跳到「行为有错」**。明确行为能力、知情程度、可预见性、选择自由和独立义务。

**概念解释型**：某现象究竟属于何种概念或应如何理解。比较不同定义的解释力、区分力、题面契合度和反例承受力；**避免把结论直接塞进定义**。

允许标注「主类型 + 次类型」：政策辩通常同时包含事实、因果和价值判断。

## 三、论证结构

- **单方成立**：证明 P 是否成立
- **A/B 比较**：证明 A 相对 B 更符合共同或更优标准
- **现状/方案比较**：比较 status quo、提出的方案和合理替代
- **程度或趋势**：证明方向、幅度与时间区间
- **必要性/充分性**：区分「没有它不行」和「有它就够」
- **因果链**：证明 A 经由机制 M 对 B 产生足够影响
- **责任归属**：证明义务、能力、违反和归责条件
- **普遍/典型情境**：题目要求覆盖所有情况、通常情况还是代表性场景

**比较是论证结构，不是与政策、价值、事实并列的命题类型。** 一个辩题可以同时是价值评价型和 A/B 比较型。

## 四、关键词最低证明标准

| 关键词 | 最低证明义务 |
|---|---|
| 有助于 | 稳定且非微不足道的正向贡献，不要求彻底解决 |
| 更 | 必须设共同参照和比较对象，不能只做单边利好陈述 |
| 应该 | 提供从事实到规范的价值桥梁，并处理成本、权利和替代 |
| 必须 / 唯一 | 承担更强的必要性和排他性证明责任 |
| 有错 | 指出具体错误或义务违反，不能只证明结果次优 |
| 改善 | 明确基线、维度、受益主体和改善幅度 |
| 当代 / 当前 | 使用与指定时期匹配的证据，避免跨时代外推 |

## 五、举证责任分配

- 主张**改变现状**的一方承担更多举证责任
- 主张**更强普遍命题**（所有/通常/必然）的一方承担更强责任
- 主张**净收益为正**的一方需处理成本与副作用
- 反对方可以只证明「问题被夸大」「方案无效」「存在更优替代」，**不必证明现状无问题**

写进诊断卡后，报告第 1 节的判准必须与它一致。

## 六、输出模板

```text
辩题诊断卡
- 逻辑改写：
- 主命题类型 / 次类型：
- 论证结构：
- 主体 / 场域 / 时间：
- 关键词最低证明标准：
- 我方论证义务：
- 对方论证义务：
- 决胜比较点：
- 主要歧义与风险：
- 当前采用的读法及理由：
- 诊断信心：高 / 中 / 低
```

诊断信心为「中 / 低」或有多种合理读法时，在报告里同时给出备选读法及各自的应对差异。
